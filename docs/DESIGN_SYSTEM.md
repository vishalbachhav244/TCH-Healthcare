# Design system

TrueCare uses self-hosted Inter Variable, Lucide icons, mineral teal accents, white operational panels and a neutral application background. Typography distinguishes page, section, table and supporting labels. Counts, time and money use tabular numerals where relevant.

Shared primitives include the facility shell, focus rings, primary and secondary buttons, status indicators, loading and error states, responsive scrollable tables, native modal dialogs, inline feedback and facility/date controls. Status text accompanies semantic colour. The patient portal uses a compact header, stacked visit cards and touch-friendly controls.

The overview chart animates only when the user permits motion. The same values are available in an adjacent table. Style tokens and responsive rules live in [styles.scss](../src/styles.scss).
