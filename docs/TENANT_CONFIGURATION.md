# Tenant configuration

The evaluation fixture includes Meridian Medical Centre, Meridian North Hospital, CityCare Hospital, Horizon Polyclinic, Sunrise Clinic and Lakeside Hospital across five tenants. Meridian executive access spans its two facilities. Sunrise Clinic and Horizon Polyclinic start in a Clinic plan with outpatient scope. Platform administrators can add organizations and facilities, assign a preset on creation, and change inpatient access where the plan permits it. Facility entitlements are versioned and loaded from persistent configuration for every request. Staff assignments for new facilities, changes to existing subscription plans, department resources and other entitlement policies remain open.

Route coverage, account assignments and guard tests are in the [authorization matrix](AUTHORIZATION_MATRIX.md).
